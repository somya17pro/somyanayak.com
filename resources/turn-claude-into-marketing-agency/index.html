Step 1: Access Open-Source Skill Packages

Explore open-source AI marketing skill repositories or curate your own custom Markdown-formatted growth playbooks.

Step 2: Package the Skill Bundle

1. Download your desired skill repository archive to your local device.
2. Navigate into the skills/ folder.
3. Right-click the individual skill folder (e.g. copywriting) and compress it into a .zip file.

Step 3: Install Skills Into Claude

1. Enable code execution inside Claude (Settings -> Capabilities -> Code execution).
2. Open Customize -> Skills -> Upload a skill.
3. Select your skill ZIP file and toggle it ON.
